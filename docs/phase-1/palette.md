- --color-text: #1F1F1F; /* quase preto */
- --color-muted: #6E6B68; /* cinza para textos secundários */

- --color-link: #7A463F; /* marrom suave para links */

Tipografia
- Primary heading: Gilda Display (serif)
- Body: Inter (sans)

Exemplo de uso
- Background app: --color-bg
- Cards / surfaces: --color-surface
- Primary buttons / accents: --color-primary
- Secondary actions: --color-accent
- Text primary: --color-text
- Muted text: --color-muted

Contrast & acessibilidade
- Garantir contraste mínimo 4.5:1 para texto normal versus background. Ajustar tons se necessário.
